기본 사용법과 적용 전 확인 사항

스카이박스 등록

1. 스카이박스 관리에서 새로 등록을 누릅니다.
2. TEX 파일 6개 또는 6개가 들어 있는 ZIP 파일을 선택합니다.
3. 파일명에는 bk / dn / ft / lf / rt / up 면 이름이 있어야 합니다.
4. 이름을 지정하고 등록하면 라이브러리에 추가됩니다.

적용 순서

1. 대시보드에서 일반 또는 랜덤 모드를 선택합니다.
2. 적용 후 플레이를 누릅니다.
3. 기존 Roblox TEX 파일은 data/Backups에 백업한 뒤 교체합니다.
4. 자동 실행 옵션이 켜져 있으면 Roblox를 실행합니다.

주의 사항

Roblox 업데이트에 따라 파일 경로 또는 파일 구성이 달라질 수 있습니다.
파일 교체에는 Roblox 설치 폴더에 대한 쓰기 권한이 필요할 수 있습니다. 필요하면 관리자 권한으로 실행하세요.
적용 전 Roblox 종료 옵션은 게임 프로세스를 강제로 종료할 수 있으므로 진행 중인 작업을 먼저 저장하세요.
